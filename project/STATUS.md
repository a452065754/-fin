## 一句话

FineReport 11.0 的 `.cpt`/`.fvs` 模板离线查看器。纯 Go 单 exe，读本机
webroot 渲染成 HTML 预览。内网无外网环境可直接部署。

## 能不能做

| 场景 | 能？ | 说明 |
|---|---|---|
| 看普通报表（CPT 表格） | ✅ | 分组/汇总/合并/横向分栏都正常 |
| 看含公式的报表 | ✅ | 求值器 1193 行 |
| 看大屏（FVS） | ✅ | 文本/图片/图表/报表块/Tab 都能渲染 |

| 查 MySQL / Oracle / SQL Server | ⚠️ | 代码就绪，**未连真库验证** |
