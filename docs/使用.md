# 使用手册

面向报表业务人员与实施顾问。介绍界面操作与 HTTP 接口。

## 1. 打开与浏览

启动程序后浏览器访问提示的地址（默认 `http://127.0.0.1:8090`）。

界面分三块：

```
┌─────────────┬──────────────────────────────────────┐
│  模板树      │  工具栏：标题 / 参数 / 缩放 / 警告     │
│  搜索框      ├──────────────────────────────────────┤
│  CPT|FVS 过滤│                                       │
│  模板列表    │  渲染区（表格 / 大屏画布）             │
│              │                                       │
│  ─────────   │                                       │
│  N个模板     │                                       │
│  数据源 3/14 │                                       │
└─────────────┴──────────────────────────────────────┘
```

### 模板树

- **搜索框**：按模板名或目录名过滤，支持 `/` 快捷键聚焦
- **过滤按钮**：`全部` / `CPT` / `FVS`
- 点击任一模板即在右侧渲染
- 底部显示模板总数

## 2. 渲染结果

### 2.1 报表参数

部分模板带参数（日期、区域等）。参数条会出现在工具栏下方，填好后点
「刷新」重新渲染。参数会通过 URL query 传给后端，并注入数据集 SQL 的
`${...}` 占位符。

### 2.2 分享与参数

- **地址栏**始终显示当前报表的链接，格式是
  `#path=<模板路径>&<参数名>=<参数值>`，**直接复制就能发给同事**，
  对方打开看到的是同一份报表、同一组参数
- 工具栏的「**复制链接**」按钮会把完整链接（含参数）复制到剪贴板
- 同一模板的**参数会被记住**：下次打开自动恢复上次的取值，
  不用每次重填
- 参数填好后点「刷新」重新渲染

### 2.3 缩放与适应

| 按钮 | 作用 |
|---|---|
| `−` / `+` | 逐级缩放（10% 一档，上限 300%） |
| `适应` | 自动缩放到窗口大小 |
| 百分比 | 显示当前缩放比 |

大屏（FVS）模板默认按 1:1 像素布局渲染，缩放不影响内部比例。

### 2.4 导出

工具栏的「**导出**」按钮提供两种方式：

- **导出图片 (PNG)**：把当前页面里的**所有图表**合成一张长图下载。
  图表是画在 canvas 上的，浏览器可以直接拿到像素，图片清晰（2 倍分辨率）。
  纯表格的报表没有 canvas，请用下面这种方式
- **打印 / 另存为 PDF**：调起浏览器的打印对话框，在目标打印机里选
  「另存为 PDF」即可。打印时会自动隐藏侧栏、工具栏等界面元素，
  只留报表本身；表格会按纸张宽度自动分页，表头在每页重复

导出文件名取报表标题，非法字符会被替换。

### 2.5 渲染提示

工具栏右侧的「警告 N」按钮。点击展开面板，列出本次渲染的所有告警，
例如：

- `地图图表已降级为柱形图`
- `数据集 X 的内置数据不完整，已使用可解码部分`
- `数据连接 MESCS 未配置密码，请设置环境变量 FINE_PWD_MESCS`

**这个面板是排查问题的第一入口** —— 报表能渲染出来不代表完全正确，
数据缺失、类型降级都会在这里列明。

### 2.6 性能面板

侧栏底部的「**性能**」按钮弹出渲染统计：

- 每个模板的**渲染次数**、**平均耗时**、**最慢一次**、**缓存命中率**、**错误数**
- 按**累计耗时**排序，最慢的在前 —— 偶尔慢一次的和一直慢的都会浮上来
- **点任意一行直接打开那个报表**
- 缓存命中的渲染记 0 毫秒（本来就没渲染成本），命中率单列显示

找「哪个报表拖慢系统」时先看这里。

### 2.7 数据源面板

左下角「数据源 N/M」。显示所有数据连接的可用状态：

| 状态 | 含义 |
|---|---|
| 可用 | FRDemo，或已配置口令的连接 |
| 缺密码 | 需要设置环境变量，面板会给出变量名 |

口令本身不显示，也不会传到浏览器。

### 3.4 公式

FineReport 单元格公式在服务端求值，失败时该格显示 `#ERROR` 并在预览底部
给出警告（写明是哪条公式、什么原因）。

**语法**

| 写法 | 含义 | 状态 |
|---|---|---|
| `=A1` / `A1:B5` | 单元格引用 / 区域引用 | ✅ |
| `$参数名` / `${参数名}` | 参数引用（支持中文名） | ✅ |
| `'2010-实际'!N5` | 跨工作表引用 | ✅ |
| `[a,b,c]A` | 数组字面量 | ✅ |
| `{a,b}` | 集合字面量（自动去重） | ✅ |
| `&` / `+` | 字符串拼接 | ✅ |
| `IF` / `IFERROR` | 条件与错误兜底（**惰性求值**，未走到的分支不计算） | ✅ |
| `B3[!0]A` | 单元格切片（按条件筛选区域） | ⚠ 未实现 |

**函数**

| 分类 | 函数 |
|---|---|
| 聚合 | `SUM` `AVERAGE`/`AVG` `COUNT` `COUNTA` `MAX` `MIN` `ACCSUM` `MOM` |
| 数学 | `ROUND` `ROUNDUP` `ROUNDDOWN` `INT` `FLOOR` `CEILING` `ABS` `SIGN` `SQRT` `MOD` `POWER` |
| 判断 | `IF` `AND` `OR` `NOT` `SWITCH` `ISNULL` `EMPTY` `IFERROR` |
| 文本 | `CONCATENATE` `LEFT` `RIGHT` `MID` `LEN` `TRIM` `UPPER` `LOWER` `REPLACE` `FIND` `SPLIT` `REPEAT` `FORMAT`/`TEXT` `CNMONEY` |
| 日期 | `TODAY` `NOW` `YEAR` `MONTH` `DAY` `WEEKDAY` `DATE` `TODATE` `DATETONUMBER` `DATEDELTA` `MONTHDELTA` `DATEINMONTH` `DATEINWEEK` `DATEDIF` |
| 数组 | `ARRAY` `RANGE` `INARRAY` `INDEXOFARRAY` `JOINARRAY` `UNIQUEARRAY` `SORT` `REVERSEARRAY` `GREPARRAY` `MAPARRAY` |
| 随机 | `RAND` `RANDBETWEEN` `UUID` |
| 跨报表 | `VALUE("报表名", 行, 列)` |
| 数据集 | `TABLEDATAFIELDS` |

> **`VALUE` 跨报表取值的限制**：被引用的报表必须以同名 `.cpt`/`.fvs` 文件存在于
> reportlets 目录。FineReport 从数据库动态加载的模板（如「5账务基础表」）
> 在磁盘上没有文件，这类引用会报「找不到报表」。

> **`GREPARRAY`/`MAPARRAY` 的 `item` 变量**：这两个函数会把当前元素绑定到
> `item`，例如 `GREPARRAY([1,2,3]A, item > 2)`。

## 4. HTTP 接口

四个只读接口，便于脚本化或集成到其他系统。

### 4.1 `GET /api/templates`

列出 reportlets 下所有 `.cpt` / `.fvs` 模板。

```json
{
  "templates": [
    {"path":"demo/basic/分组统计.cpt","name":"分组统计","kind":"cpt","dir":"demo/basic","size":23645}
  ],
  "count": 1770
}
```

`path` 是相对 reportlets 的路径，斜杠分隔，可直接传给 `/api/preview`。

### 4.2 `GET /api/preview?path=...&参数=值`

渲染模板。`path` 支持相对路径或 reportlets 内的绝对路径；
其余 query 参数会作为模板参数注入。

响应体是 `Preview` 对象，结构随模板类型而变：

```json
{
  "path": "demo/basic/分组统计.cpt",
  "name": "分组统计",
  "kind": "cpt",
  "title": "分组统计",
  "params": [{"name":"日期","default":"2026-01-01"}],
  "sheets": [{
    "name": "sheet1",
    "width": 1142.6, "height": 2595.0,
    "cols": [232, 193.3, 174.6],
    "rows": [57.3, 0, 0],
    "cells": [{
      "r": 5, "c": 0, "rs": 5, "cs": 1,
      "text": "产品组A",
      "style": {"fontSize": 12, "hAlign": "left", "borderBottom": "1px solid #ccc"},
      "chart": null
    }]
  }],
  "warnings": ["..."],
  "error": ""
}
```

- `cells` 用 `r`/`c` 表示行列坐标，`rs`/`cs` 表示跨行跨列数
- `chart` 非空时表示该单元格是图表，结构见 4.5
- `error` 非空表示渲染失败，`warnings` 是非致命告警
- 响应头 `X-Render-Ms` 给出本次渲染耗时（毫秒）

FVS 模板返回 `pages` 而非 `sheets`：

```json
{
  "pages": [{
    "name": "页面1",
    "width": 957, "height": 533,
    "background": "#0e1a2b",
    "backgroundImage": "/api/fvs/asset?tpl=...&id=...",
    "widgets": [
      {"id":"w1","type":"text","x":20,"y":30,"w":200,"h":40,"text":"标题","style":{...}},
      {"id":"w2","type":"chart","x":20,"y":90,"w":400,"h":300,"chart":{...}},
      {"id":"w3","type":"report","x":20,"y":400,"w":400,"h":200,"sheet":{...}}
    ]
  }]
}
```

### 4.3 `GET /api/fvs/asset?tpl=...&id=...`

取 FVS 内嵌资源（背景图、字体、媒体文件），返回二进制内容。

### 4.4 `GET /api/connections`

列出所有数据连接。

```json
{
  "connections": [
    {"name":"FRDemo","kind":"sqlite","url":"jdbc:sqlite://${ENV_HOME}/../help/FRDemo.db","needsPassword":false,"resolved":false},
    {"name":"MESCS","kind":"oracle","url":"jdbc:oracle:thin:@192.168.0.28:1521:orcl","username":"XYDS","needsPassword":true,"passwordEnv":"FINE_PWD_MESCS","resolved":false}
  ],
  "total": 14,
  "ready": 2
}
```

`resolved` 表示该连接的口令是否已在环境中找到。

### 4.5 `GET /api/health`

服务健康状态，供监控采集。

```json
{
  "status": "ok",
  "webroot": "D:////tomcat-win64////webapps////webroot",
  "reportlets": "D:////tomcat-win64////webapps////webroot////WEB-INF////reportlets",
  "connections": [
    {"name": "FRDemo", "kind": "sqlite", "ready": true, "resolved": false},
    {"name": "MESCS", "kind": "oracle", "ready": false, "resolved": false}
  ],
  "ready": 1,
  "total": 14,
  "metrics": {"requests": 42, "errors": 0, "slow": 1, "uptimeSeconds": 3600}
}
```

`ready` 是当前可用的数据源数量（FRDemo 免密，或口令已配置的连接）。
`metrics.slow` 是超过 3 秒的慢请求数，通常意味着某个库或模板偏慢。

### 4.6 `GET /api/audit`

最近的访问记录（审计日志）。`?limit=` 控制条数，最多 500。

```json
{
  "entries": [
    {
      "time": "2026-10-21T00:33:57+08:00",
      "user": "viewer",
      "address": "127.0.0.1",
      "action": "preview",
      "path": "demo/basic/分组统计.cpt",
      "params": "区域=华东",
      "status": 200,
      "costMs": 9
    }
  ],
  "count": 1,
  "file": true
}
```

`file` 表示是否在写日志文件（由 `RV_AUDIT_LOG` 决定）。不写文件时记录
只保留在内存里，重启即清空。

### 4.7 `GET /api/perf`

各模板的渲染统计，按累计耗时降序。`?limit=` 控制条数，最多 500。

```json
{
  "templates": [
    {
      "path": "demo/basic/分组统计.cpt",
      "count": 2, "hits": 1, "misses": 1,
      "totalMs": 7, "avgMs": 3.5, "maxMs": 7, "lastMs": 0,
      "errors": 0, "hitRate": 0.5
    }
  ],
  "count": 1,
  "tracked": 1
}
```

`tracked` 是当前在跟踪的模板总数（上限由 `RV_PERF_MAX` 决定，默认 200）。

### 4.8 图表数据结构

```json
{
  "kind": "combo",
  "title": "标题",
  "categories": ["国家A", "国家B"],
  "series": [
    {"name":"数量","type":"bar","data":[10, 20]},
    {"name":"辅助","type":"line","data":[5, 8],"axis":"y1"}
  ],
  "colors": ["#2563eb", "#f59e0b"],
  "legend": true,
  "legendPos": "bottom",
  "stack": false,
  "horizontal": false,
  "combo": true
}
```

`kind` 取值：`bar` / `line` / `area` / `pie` / `funnel` / `scatter` /
`bubble` / `radar` / `gauge` / `combo` / `gantt` / `map` / `heatmap` /
`sunburst` / `treemap` / `multipie` / `wordcloud` / `box`。

气泡图额外有 `series[].size`（半径数组）、`axisLabel`（X/Y 轴名）、
`axisValues`（X 值数组）。甘特图有 `horizontal: true`。

## 5. 排障速查

| 现象 | 检查 |
|---|---|
| 报表空白 | 点「警告」按钮看告警 |
| 数字不对 | 确认连的是哪个库（面板里看连接名）；确认参数填了 |
| 图表不显示 | 该类型可能未实现，看告警文字 |
| 大屏缺图 | FVS 内嵌数据解码截断，只用了可解码部分 |
| 页面卡 | 模板数据量大会渲染慢，看 `X-Render-Ms` 响应头 |
| 列表慢 | 首次扫描全量模板，程序有 30 秒缓存 |
