# 部署手册

面向运维/实施人员。目标是让一个不了解本项目的人，照着本文能独立完成安装、
配置与验证。

## 1. 运行前提

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 7+ / Linux（已验证 Windows 10 + PowerShell） |
| 运行时 | **无**。产物是单个 exe，不依赖 Node / Python / JRE / 数据库客户端 |
| 内存 | 常驻约 40–80 MB |
| 磁盘 | exe 约 25 MB |
| 网络 | 需能读取本机 FineReport webroot；需能访问所选数据源（若报表查真实库） |
| Go（仅编译时需要） | 1.22+ |

## 2. 获取产物

### 方式 A：直接用发布产物（推荐给部署方）

从仓库 Releases 下载 `reportviewer.exe`（Windows）或 `reportviewer`（Linux），
放到目标机器任意目录。

### 方式 B：从源码构建

```bash
git clone https://github.com/a452065754/-fin.git
cd -fin
go build -o bin/reportviewer.exe ./cmd/reportviewer
```

**Windows 构建注意**：若默认 build cache 目录不可写（报错
`Access is denied`），先指定一个可写目录：

```bash
export GOCACHE=$(pwd)/.gocache      # Git Bash
set GOCACHE=%CD%\.gocache            # CMD
```

### 交叉编译 Linux

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o reportviewer ./cmd/reportviewer
```

> CGO 必须为 0。所有数据库驱动都是纯 Go 实现，开启 CGO 会引入
> 对 C 工具链的依赖，破坏「单文件直接扔」的目标。

## 3. 配置

### 3.1 定位 webroot

程序需要 FineReport 的 webroot 目录（里面含 `WEB-INF`）。按以下顺序探测：

1. 环境变量 `FR_WEBROOT`
2. `F:\tomcat-win64\webapps\webroot`
3. `C:\tomcat-win64\webapps\webroot`
4. `D:\tomcat-win64\webapps\webroot`
5. 当前工作目录下的 `webroot/`

都不存在时用第 2 项作为默认值并在启动时报错。**建议显式指定**：

```bash
./reportviewer.exe -webroot "D:\tomcat-win64\webapps\webroot"
```

### 3.2 命令行参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-webroot` | 自动探测 | FineReport webroot 目录（含 WEB-INF） |
| `-reportlets` | `<webroot>/WEB-INF/reportlets` | 模板目录，指向别的目录可只看子集 |
| `-addr` | `:8090` | HTTP 监听地址 |

`FR_WEBROOT` 环境变量与 `-webroot` 等价，命令行参数优先。

### 3.3 服务级环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `RV_USER` | 空 | Basic 认证用户名 |
| `RV_PASSWORD` | 空 | Basic 认证口令 |
| `RV_TIMEOUT` | `60s` | 单次渲染的超时上限 |

**认证**：只有 `RV_USER` 和 `RV_PASSWORD` **都设置**才会启用。只设一个
不启用认证（避免半配置把所有人锁在外面）。启用后所有接口都需要
`Authorization: Basic ...`，浏览器会弹窗询问。

```bat
set RV_USER=viewer
set RV_PASSWORD=你的口令
set RV_TIMEOUT=90s
reportviewer.exe -addr :8090
```

**超时**：`RV_TIMEOUT` 接受 `90s` 这类时长写法，也接受纯数字（按秒算）。
超过时限的渲染会被中止，避免一个慢查询长期占着源库连接。

### 3.4 数据源口令（按需）

程序会自动发现 webroot 里配置的所有数据连接。若报表需要查**非 FRDemo**
的库，必须注入口令。

**查看需要哪些变量**：启动程序 → 左下角点「数据源」→ 面板里每个标红
「缺密码」的连接会显示它需要的环境变量名。

命名规则：

| 连接名 | 环境变量 |
|---|---|
| `MESCS`（纯 ASCII） | `FINE_PWD_MESCS` |
| `气密检测77`（含中文） | `FINE_PWD_E6B094E5AF86E6A380E6B58B3737` |

中文连接名的变量名 = `FINE_PWD_` + 连接名 UTF-8 字节的十六进制（大写）。

设置示例（CMD）：

```bat
set FINE_PWD_MESCS=你的密码
reportviewer.exe -addr :8090
```

设置示例（PowerShell）：

```powershell
$env:FINE_PWD_MESCS = "你的密码"
.\reportviewer.exe -addr :8090
```

> 口令只存在进程环境变量里，**不落盘、不写日志、不返回给浏览器**。
> 修改后需重启程序。

## 4. 启动

### 4.1 前台运行（调试用）

```bash
./reportviewer.exe -addr :8090
```

启动成功会打印：

```
报表查看器已启动: http://127.0.0.1:8090
webroot:    D:\tomcat-win64\webapps\webroot
reportlets: D:\tomcat-win64\webapps\webroot\WEB-INF\reportlets
```

### 4.2 注册为 Windows 服务

用 [nssm](https://nssm.cc/)：

```bat
nssm install OpsWatchReportViewer "D:\ops\reportviewer.exe" "-addr :8090"
nssm set OpsWatchReportViewer AppEnvironmentExtra FINE_PWD_MESCS=你的密码
nssm set OpsWatchReportViewer DisplayName "报表查看器"
nssm set OpsWatchReportViewer Description "FineReport 模板离线查看器"
nssm start OpsWatchReportViewer
```

### 4.3 Linux 后台常驻

```bash
nohup ./reportviewer -addr :8090 >> /var/log/reportviewer.log 2>&1 &
```

> **坑**：SSH 断开可能杀掉后台进程。必须用 `nohup ... &`（或 `setsid`），
> 单纯 `./reportviewer &` 会在会话结束时被回收。

### 4.4 开机自启（Linux）

写 `/etc/systemd/system/reportviewer.service`：

```ini
[Unit]
Description=FineReport Report Viewer
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/reportviewer
ExecStart=/opt/reportviewer/reportviewer -addr :8090
Environment=FINE_PWD_MESCS=你的密码
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now reportviewer
```

## 5. 验证

启动后按顺序检查：

```bash
# 1. 模板列表（应返回模板总数，示例环境约 1770）
curl http://127.0.0.1:8090/api/templates

# 2. 连接状态（应看到 total / ready 两个数字）
curl http://127.0.0.1:8090/api/connections

# 3. 渲染一个模板（FRDemo 报表，应返回 sheets 数组）
curl "http://127.0.0.1:8090/api/preview?path=demo/basic/%E5%88%86%E7%BB%84%E7%BB%9F%E8%AE%A1.cpt"

# 4. 健康检查（应返回 status=ok 与各数据源状态）
curl http://127.0.0.1:8090/api/health
```

**开启了认证时**，每个请求都要带凭据：

```bat
curl -u viewer:你的口令 http://127.0.0.1:8090/api/health
```

浏览器打开首页，左侧应出现模板树。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报「FineReport webroot 不存在」 | 路径错或 FineReport 未部署 | 用 `-webroot` 显式指定 |
| 启动报「reportlets 目录不存在」 | webroot 对了但不是 FR 安装目录 | 确认 `<webroot>/WEB-INF/reportlets` 存在 |
| 模板列表为空 | reportlets 路径不对 | 用 `-reportlets` 指定 |
| 报表数据为空，提示「数据集不存在」 | 模板引用的数据集在本次渲染中未加载 | 看「渲染提示」面板的具体告警 |
| 提示「数据连接 X 未配置密码」 | 未设环境变量 | 按 3.3 设置并重启 |
| 提示「连接数据源 X 失败」 | 库不可达 / 口令错 / 端口被防火墙拦 | 先 `telnet IP 端口` 验证网络 |
| 页面能开但图表空白 | 该图表类型尚未实现或数据为空 | 看「渲染提示」面板 |
| 端口被占用 | 8090 已被占用 | 换 `-addr` |

## 7. 卸载

1. 停止服务（`nssm stop` / `systemctl stop` / 结束进程）
2. 删除 exe 目录
3. 如设置了环境变量，清理之

程序**不写任何持久化文件**，除自身 exe 外无残留。webroot 内的文件一律只读。
