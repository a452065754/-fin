## 1. 一句话说明

**reportviewer** 是用纯 Go 写的 FineReport 11.0 报表模板离线查看器。读取
本机 FineReport 的 webroot，把 `.cpt`（报表模板）和 `.fvs`（大屏模板）
渲染成 HTML 预览，编译为单个 exe 部署在无外网的内网服务器上。

## 2. 为什么做这个

FineReport 11.0 没有 Linux 版，且内网隔离无法用云服务。业务方需要在
**不启动完整 Tomcat 环境**的前提下查看报表。目标是：复制一个 webroot 到
任意机器，跑一个 exe 就能看报表。

**选 Go 的原因**（原始决策记录）：Node.js 需要在内网服务器重新配置依赖
环境，Go 编译后是单文件、零运行时依赖。

**推送方式**：SSH 22 端口在本机不通，**必须走 HTTPS**。本机有缓存的
git 凭据，`git push` 可直接成功。

**CI**：`.github/workflows/ci.yml` 在 push/PR 到 main 时自动跑
gofmt、go vet、go test、构建、前端语法、三个前端断言、刷新状态快照、
文档自检。CI 机器上没有 FineReport，相关用例会**自动 skip**（不失败），
用 `FR_TEST_WEBROOT` 可指定模板目录。

**状态数字不会过期**：`project/STATUS.md` 的硬指标区块由
`tools/gen_status.py` 从代码直接统计（测试数、图表类型数、接口数、
代码行数、环境变量数），`tools/verify_docs.py` 会检查该区块是否最新。
**改了代码后跑一次 `python3 tools/gen_status.py` 即可。**

> push 时会打印一行
> `git-credential-manager.exe: No such file or directory` —— **这是噪音，
> 不影响推送**。全局 credential helper 指向了一个已删除的旧版本路径，
> 靠缓存凭据兜底。看到这行不要慌，看 push 结果行即可。

**GitHub MCP connector 无建仓权限**（403 `Resource not accessible by

### 本机特有的坑

1. **Go build cache 默认目录不可写** → 报 `Access is denied`。
   必须 `export GOCACHE=$(pwd)/.gocache`。
2. **代理**：`https://goproxy.cn,direct` 可用。但公司代理会吞本地请求，
   测 HTTP 接口时用 `curl --noproxy '*'`。
3. **沙箱内长驻进程**：`Start-Process -WindowStyle Hidden` 活不过当前工具
   调用，用后台任务方式启动。
4. **数据库端口在本机全部不通**（不在内网），测真库必须到内网机器。

## 10. 交接给下一位时的提醒

以下都是实际踩过的坑，**别再踩一遍**：

1. **测试必须断言数据量**，只断言类型会假通过（combo/gantt/structure 都中过）
2. **图表类型分支要按特异性排序**，`heatmap` 含 `map`，顺序错了会误判
3. **`Find` 会递归整棵树**，拿不准层级时先加 trace 打 print 看结构
4. **别改 `toFloat` 语义**，公式层共用；图表层加 `toFloatOrDate` 包装
5. **改完模板/静态资源要重启实例**，前端有缓存，否则看到旧 HTML
6. **db.script 的 `"','"` 是 3 个字符**，按 2 跳会带出多余单引号
7. **中文连接名在 db.script 的 key 里是 `\uXXXX`**，要还原
8. **`CGO_ENABLED=0` 不能破**，破了单文件部署的目标就没了
9. **push 报 credential-manager 缺失是噪音**，看结果行
10. **改完 Go 代码要确认二进制重编译**，别只改源码
